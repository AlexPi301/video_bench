# Video Bench Helpers

Helper utilities for the Video Bench backend. Each helper lives in its own
module and is re-exported from `helpers/__init__.py` so it can be imported as:

```python
from helpers import MODE, retrieve_captions
```

## `retrieve_captions`

Retrieve the captions that fall inside a time range from a captions directory.
The retrieval behavior is selected with `MODE.IMAGE_BASED` or
`MODE.VIDEO_BASED`.

### Signature

```python
retrieve_captions(
    captions_dir: str | Path,
    video_name: str,
    start_timestamp: float | int | str,
    end_timestamp: float | int | str,
    mode: MODE | str,
) -> list[dict[str, Any]]
```

The function takes **5 required parameters**:

| Parameter             | Type                       | Description                                                                                       |
| --------------------- | -------------------------- | ------------------------------------------------------------------------------------------------- |
| `captions_dir`        | `str` or `pathlib.Path`    | Directory containing caption JSON files.                                                          |
| `video_name`          | `str`                      | Required video name. In video-based mode, only JSON files whose file names start with this value are considered. |
| `start_timestamp`     | `float`, `int`, or `str`   | Lower bound of the time range. A number is interpreted as **milliseconds**; a string as `HH:MM:SS.mmm`. |
| `end_timestamp`       | `float`, `int`, or `str`   | Upper bound of the time range. Same conventions as `start_timestamp`.                             |
| `mode`                | `MODE` or `str`            | `MODE.IMAGE_BASED` / `"IMAGE_BASED"` or `MODE.VIDEO_BASED` / `"VIDEO_BASED"`.                  |

### Modes

#### `MODE.IMAGE_BASED`

The function expects `captions_dir/captions.json` to exist. If it does not
exist, `FileNotFoundError` is raised.

`captions.json` must follow the video_bench captions format used by files such
as `input/airport_walk/airport_walk_normal_meta/captions.json`:

```json
{
  "type": "video_bench_captions",
  "version": 1,
  "video_name": "airport_walk_normal.mov",
  "caption_count": 332,
  "captions": [
    {
      "frame_index": 0,
      "timestamp_ms": 0,
      "timestamp": "00:00:00.000",
      "caption": "This wide-angle shot captures ..."
    },
    {
      "frame_index": 45,
      "timestamp_ms": 1500,
      "timestamp": "00:00:01.500",
      "caption": "Under an overcast, pale grey sky ..."
    }
  ]
}
```

Only the `captions` array is read. Each entry is expected to have a numeric
`timestamp_ms` field; entries without one are skipped. The return value is the
list of entries whose `timestamp_ms` falls inside the inclusive requested range,
in file order.

#### `MODE.VIDEO_BASED`

The function does not look for `captions.json`. Instead, it scans `*.json` files
inside `captions_dir` and all of its subdirectories whose file names start with
`video_name`. JSON files with other filename prefixes are ignored.

Each JSON file must follow the segment annotation format generated by
`course_material/documents/captions/segment_and_caption_pipeline.py`, for
example:

```json
{
  "video_path": "/path/to/plane_starting_segment_0.mov",
  "original_video_path": "/path/to/plane_starting.mov",
  "segment_index": 0,
  "start_time_sec": 0.0,
  "end_time_sec": 60.0,
  "model_name": "gemini-3.1-pro-preview",
  "annotation_raw": "**1. Objects and Attributes:** ...",
  "timestamp": "2026-06-28T12:00:00"
}
```

Matching-prefix files whose `[start_time_sec, end_time_sec]` overlaps the
requested range are returned.

### Return value

A list of matching caption entries. Each entry is returned verbatim with all of
its original fields.

For `MODE.IMAGE_BASED`, entries are individual objects from the `captions` list.
For `MODE.VIDEO_BASED`, entries are whole segment annotation JSON objects.

### Errors

| Exception             | When                                                                                  |
| --------------------- | ------------------------------------------------------------------------------------- |
| `FileNotFoundError`   | `captions_dir` does not exist, or `MODE.IMAGE_BASED` cannot find `captions_dir/captions.json`. |
| `ValueError`          | A caption file is not valid JSON, a file is missing required fields for the selected mode, `video_name` is empty, `mode` is invalid, or `start_timestamp > end_timestamp`. |
| `TypeError`           | `video_name` is not a string, or a timestamp is neither a number nor a string.        |

### Examples

```python
from helpers import MODE, retrieve_captions

image_captions_dir = (
    "/workspaces/practical_course_cvhci/input/airport_walk/"
    "airport_walk_normal_meta"
)

# Timestamps as milliseconds (matches the timestamp_ms field)
entries = retrieve_captions(
    image_captions_dir,
    "airport_walk_normal",
    0,
    5000,
    MODE.IMAGE_BASED,
)

# Timestamps as HH:MM:SS.mmm strings (matches the timestamp field)
entries = retrieve_captions(
    image_captions_dir,
    "airport_walk_normal",
    "00:00:00.000",
    "00:00:05.000",
    MODE.IMAGE_BASED,
)

# Mixed units are allowed
entries = retrieve_captions(
    image_captions_dir,
    "airport_walk_normal",
    1500,
    "00:00:10.000",
    MODE.IMAGE_BASED,
)

for entry in entries:
    print(entry["timestamp"], entry["frame_index"], entry["caption"][:80])
```

```python
from helpers import MODE, retrieve_captions

video_captions_dir = (
    "/workspaces/practical_course_cvhci/course_material/documents/captions/"
    "captions/Alec/airport_landebahn"
)

# Returns plane_starting*.json segment annotations overlapping 61s-119s.
entries = retrieve_captions(
    video_captions_dir,
    "plane_starting",
    61_000,
    119_000,
    MODE.VIDEO_BASED,
)

for entry in entries:
    print(entry["segment_index"], entry["start_time_sec"], entry["annotation_raw"][:80])
```

### Time range semantics

For `MODE.IMAGE_BASED`, the range is **inclusive on both ends**: a caption whose
`timestamp_ms` equals `start_timestamp` or `end_timestamp` is included.

For `MODE.VIDEO_BASED`, a segment is included when its
`[start_time_sec, end_time_sec]` interval overlaps the requested range.

When stitching adjacent image-based ranges, use a non-overlapping boundary (for
example, `[0, 5000]`, then `[5001, ...]`) if you need to avoid selecting the same
caption twice.
